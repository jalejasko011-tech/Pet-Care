# Pet Care World 1.8.5 — easier birth-date entry

Version code 16. Caregiver setup uses separate day/month selectors and a numeric four-digit year entry. No birth date is preselected. Impossible dates, including invalid leap days, are rejected; age validation and local-only handling remain in force. Closing the setup clears the values.

Retains the 1.8.4 family controls and privacy/reminder changes. See RELEASE_1_8_4.md and PHONE_ACCEPTANCE_1_8_4_SR.md for their scope and remaining physical-phone/Firebase moderation acceptance. This release does not activate paid services or submit the app to Google Play.
