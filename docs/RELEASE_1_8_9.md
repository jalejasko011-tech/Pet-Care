# Pet Care World 1.8.9 — family care in main navigation

Version code 20. Home, Pets, Health, Memories, Family care and More are directly visible in the main navigation. Narrow screens use two rows of three generous buttons, with no horizontal scrolling. Active destinations expose aria-current. Family care no longer lights up More. Family joining is available before creating a separate local pet; the local caregiver form is shown only for a local pet.

Sharing behavior, Firebase configuration and production rules are unchanged from 1.8.8. The existing three-identity production acceptance and permission suites remain relevant. This release adds browser checks for direct family access, Back, selection, SR/EN/RTL and touch-target geometry at 320–768px, plus Android WebView direct-family/Back assertions. Existing localization, backup, reminder and Firebase suites still gate release.

Install over the current app with the existing signing certificate. Physical phone/OEM acceptance, operational moderator verification and Play registration/declarations/review remain pending. No paid backend or media/push activation is included.
