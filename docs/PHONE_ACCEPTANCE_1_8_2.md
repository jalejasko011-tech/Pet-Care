# Pet Care World 1.8.2 — owner acceptance

Update the installed app with the signed 1.8.2 APK (version code 13). Do not
uninstall the existing app. The release pipeline uses the existing signing key.
Keep the private complete ZIP backup that was already saved outside the app.

## Breed and species entry

1. Open Pets and edit an existing pet. Existing breed text must remain intact.
2. Add a test dog. Type part of a breed name and select a suggestion. Serbian
   suggestions include names such as Nemački ovčar and Zlatni retriver.
3. Change the animal category to Cat. Suggestions must change and the prior dog
   breed must clear. Choose a cat breed or enter a custom name and save.
4. Reopen the profile and restart the app. Species and breed must remain correct.
5. For birds, fish and reptiles the suggestions describe species rather than
   claiming that they are dog-style breeds. A custom name is always allowed.

There are 456 suggestions across 43 pet categories, including Other, with
132 dog and 51 cat entries. The list is not an exhaustive breed registry.

## Language changes

1. Start a profile and enter a name, custom breed and a photo without saving.
2. Change language with the flag selector. Form values and the photo must remain.
3. Check Serbian, English and another selected language, then Arabic for RTL.
4. Save the profile, close the app and reopen it. The chosen language persists;
   the original user-entered name, breed and notes must not be translated.
5. Check More, Health, Reminders, Meals, Settings, private Memories and the
   printable health record. Check for clipped labels and horizontal page overflow.

All twenty requested languages and the four existing additional options remain
available offline. Additional language copy includes machine translation and is
not certified as reviewed by native speakers. The legal pages retain their
existing authoritative English and Serbian text.

## Existing functionality

Check an ordinary reminder with the screen locked, and a reminder after reboot
and the first unlock. Keep precise-alarm and notification access enabled on the
phone. Verify a complete backup and a private photo memory. These phone checks
are owner acceptance for this update, distinct from emulator and browser CI.

No paid Firebase feature is activated by this release. Google Play registration,
closed testing and publication are separate from downloading the GitHub APK.
